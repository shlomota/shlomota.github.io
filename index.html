Now

At AWS I sit on the science side of a production DevOps agent — the kind that gets paged, reads the telemetry, and proposes a mitigation. My work is the unglamorous half of that sentence: how do you know it worked?

Agent evaluation is harder than model evaluation. A trajectory can reach the right answer through reasoning you would never ship, or fail for reasons that have nothing to do with the model. So most of my time goes into measurement that survives contact with production traffic.

SRE mitigation
Measuring whether an agent's proposed remediation is correct, safe, and actually resolves the incident — not merely plausible.
Benchmarking
Offline suites that discriminate between agent versions, and scalable online evaluation that keeps working once real customers are in the loop.
Trajectory analysis
Agentic harnesses that read real agent runs to find confounders, trace which features helped, and turn failures into something a model can learn from.

Previously: three years at Check Point training transformers to catch malicious email and account takeover, at a scale where false positives are expensive and attackers adapt weekly.

Papers

Computational philology — using NLP to date, attribute, and recover rabbinic texts transmitted orally for centuries before anyone wrote them down.

  1. 2026

    Pragmatic Computational Philology: Yalqut Shim‘oni, Yelammedenu, and the Lost Midrashim of Ashkenaz

    Jewish Studies, an Internet Journal (JSIJ)

    Applies the style-classification machinery to the Yalqut Shim‘oni anthology to argue for the Ashkenazi transmission of otherwise lost Yelammedenu material.

  2. 2023

    Style Classification of Rabbinic Literature for Detection of Lost Midrash Tanhuma Material

    Journal of Data Mining & Digital Humanities  ·  with Nachum Dershowitz and Moshe Lavee

    Midrash collections are multilingual works shaped by long, unstable oral and written transmission, which makes the origin of any given passage genuinely contested. We classify rabbinic passages by style using Hebrew language models, then combine that signal with text-reuse detection to surface passages of lost Midrash Tanhuma preserved inside later anthologies.

    arXiv:2211.09710 journal code

  3. 2022

    Style Classification of Hebrew Texts in Midrashic Literature

    M.Sc. thesis  ·  Tel Aviv University

    The thesis behind the papers above. Earlier, as an undergraduate at the Hebrew University: Does BERT Have Common Sense?

Projects

Weekend systems, mostly. Each one exists because something was annoying enough to fix.

  • Meowify

    Turns any song into a cat-meow cover. Demucs splits the vocal stem, an energy heuristic finds the chorus, and the vocal line comes back as meows. Built because my kids went through a meowing phase and would not stop.

    Demucs · librosa · Suno · yt-dlp

    meowify.click code write-up

  • MeloDetective

    Shazam for melodies: hum a tune and it finds the recording. Demucs isolates the vocals, Melodia converts them to a pitch contour, and dynamic time warping over a vector index matches the shape of the melody rather than the audio itself — so a borrowed tune with different lyrics still matches.

    Demucs · Melodia · DTW · vector search

    code write-up

  • Polymarket Analyzer

    Anomaly detection for prediction markets. Builds per-market leaderboards from trade history and flags accounts whose timing is too good — written after one account made $400K on the Maduro market over a weekend.

    Python · Streamlit · Polymarket API

    code write-up

  • MishnahBot

    Cross-lingual RAG over the Mishnah: ask in English, retrieve over the Hebrew, answer with the original text alongside. A study in what happens to retrieval quality when the query language and the corpus language disagree.

    RAG · embeddings · Hebrew NLP

    code write-up

  • KtuvitBot

    A Telegram bot that subtitles and translates any video in two clicks. Whisper transcribes, a frontier model translates, subtitles get burned in and the SRT comes back too. An /enhance mode runs two transcription models in parallel and merges the better parts of each; RTL fixes keep Hebrew readable.

    Whisper · GPT · ffmpeg · Telegram

    code write-up

  • Chess-puzzle VQA benchmark

    Can a multimodal model read a chessboard? I scored GPT-4o, Claude, Grok and others on screenshot → FEN conversion, measuring edit distance and board-level correctness. Several models confidently promoted a pawn to a rook. Shipped as a custom GPT that turns a screenshot into an analysis link.

    Multimodal eval · FEN · edit distance

    write-up

  • Amazon AI Shopper

    A Chrome extension that filters search results by plain-English criteria — "hard plastic, for adults", "Nike only" — and strips the sponsored-adjacent noise out of the page. Bring your own API key.

    Chrome extension · JavaScript · LLM filtering

    Chrome Web Store code

  • Wiki Blame & Bias Analyzer

    git blame for Wikipedia. Binary-searches an article's revision history to find when a particular phrase first appeared, who added it, and what the edit looked like — including the awkward case where text was added, removed, and quietly restored.

    MediaWiki API · binary search · Streamlit

    code

  • Midrash Style Classification

    Code for the Tanhuma paper: a text-reuse engine paired with a style classifier, plus a Streamlit app that scores an arbitrary Hebrew passage for Tanhuma-style and tells you where else it shows up in the corpus.

    Hebrew BERT · text reuse · Streamlit

    code paper

  • AtariHacker

    Beating an Atari game with classical computer vision and no learning at all — detect the blocks, predict the crossing, press the button. A useful reminder of what a well-chosen heuristic still buys you.

    OpenCV · motion prediction
